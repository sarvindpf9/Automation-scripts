# Packer Linux Image Builder Skill

## Behaviour

- Ask two of the most-blocking unknown before proceeding. If the distro family is not specified, ask that first — it determines the entire autoinstall mechanism.
- Never invent ISO URLs, checksums, package lists, or usernames. Use clearly marked placeholders: `<ISO_URL>`, `<ISO_CHECKSUM_SHA256>`, `<SSH_USERNAME>`, etc.
- If the user provides a package list, embed it directly in `scripts/provision.sh`. If they say "I'll add packages myself," emit provision.sh with a clearly labelled section comment and no packages.
- Produce all files as a complete set. Do not emit a single file in isolation unless explicitly asked.
- After emitting all template files, invoke the `readme-writer` skill to generate `README.md` in the same directory.

---

## Intake Questions (ask only the blocking ones, one at a time)

Before generating, confirm the following. Skip any already answered in the user's input:

1. **Distro family** — Ubuntu/Debian (preseed/autoinstall) or RHEL/Rocky/Alma (kickstart)? This is always the first question if not provided.
2. **Distro version** — e.g., Ubuntu 24.04, Rocky 9.3. Needed for correct boot command and preseed/ks format.
3. **Output filename slug** — used for the directory name and the `output_filename` variable default.
4. **Package list** — what packages beyond the base OS should be installed? Accept "none" or "I'll fill it in."
5. **Custom users** — any non-root users to create, or SSH keys to inject?

---

## File Set

Every invocation produces exactly these files:

```
06-packer/<nn>-<distro>-<slug>/
├── linux.pkr.hcl              # Packer template: QEMU source, SSH provisioner, qcow2 post-processor
├── variables.pkrvars.hcl      # User-facing variable overrides (ISO path, disk size, etc.)
├── http/
│   └── preseed.cfg            # Ubuntu/Debian: fully-automatic preseed
│   └── ks.cfg                 # RHEL/Rocky/Alma: kickstart (emit one, not both)
├── scripts/
│   ├── provision.sh           # Package installs and OS customisation
│   └── cleanup.sh             # Pre-packaging sysprep (clear keys, machine-id, caches)
└── README.md                  # Generated by readme-writer skill
```

`output-<slug>/` is written at build time by Packer — it is a generated artefact, not a static file.

No `curtin/` or `drivers/` directories are needed for Linux. The Windows template's `http/logon.ps1` and `http/rh.cer` have no Linux equivalent and must not be included.

## Canonical File Templates

### `linux.pkr.hcl`

```hcl
packer {
  required_version = ">= 1.9.0"
  required_plugins {
    qemu = {
      version = "~> 1.0"
      source  = "github.com/hashicorp/qemu"
    }
  }
}

# ── Variables ──────────────────────────────────────────────────────────────────

variable "iso_url" {
  type        = string
  default     = "<ISO_URL>"
  description = "Full URL or local path to the installation ISO."
}

variable "iso_checksum" {
  type        = string
  default     = "sha256:<ISO_CHECKSUM_SHA256>"
  description = "Checksum of the ISO in 'algorithm:value' format."
}

variable "disk_size" {
  type        = string
  default     = "20G"
  description = "Size of the VM's root disk during build."
}

variable "memory" {
  type        = number
  default     = 2048
  description = "RAM in MB allocated to the build VM."
}

variable "cpus" {
  type        = number
  default     = 2
  description = "vCPUs allocated to the build VM."
}

variable "headless" {
  type        = bool
  default     = true
  description = "Set false to open a VNC viewer during the build (useful for debugging)."
}

variable "ssh_username" {
  type        = string
  default     = "<SSH_USERNAME>"
  description = "Username Packer uses to SSH into the build VM."
}

variable "ssh_password" {
  type        = string
  default     = "<SSH_PASSWORD>"
  sensitive   = true
  description = "Password matching the one set in preseed.cfg / ks.cfg."
}

variable "ssh_timeout" {
  type        = string
  default     = "30m"
  description = "How long Packer waits for SSH to become available after boot."
}

variable "output_filename" {
  type        = string
  default     = "<DISTRO>-<SLUG>-<VERSION>.qcow2"
  description = "Filename of the final qcow2 image written into output-<slug>/."
}

# ── Source ─────────────────────────────────────────────────────────────────────

source "qemu" "linux_builder" {
  accelerator      = "kvm"
  machine_type     = "q35"
  cpus             = var.cpus
  memory           = var.memory
  disk_size        = var.disk_size
  disk_interface   = "virtio"
  net_device       = "virtio-net"
  format           = "qcow2"
  headless         = var.headless

  iso_url          = var.iso_url
  iso_checksum     = var.iso_checksum
  http_directory   = "http"

  # Boot command is distro-specific — see Constraints section
  boot_wait        = "5s"
  boot_command     = local.boot_command

  communicator     = "ssh"
  ssh_username     = var.ssh_username
  ssh_password     = var.ssh_password
  ssh_timeout      = var.ssh_timeout
  shutdown_command = "echo '${var.ssh_password}' | sudo -S shutdown -P now"

  vnc_bind_address = "127.0.0.1"
}

# ── Locals ─────────────────────────────────────────────────────────────────────

locals {
  # Replace this block with the correct boot_command for the target distro.
  # See the Distro-Specific Boot Commands section below.
  boot_command = ["<BOOT_COMMAND_PLACEHOLDER>"]
}

# ── Build ──────────────────────────────────────────────────────────────────────

build {
  sources = ["source.qemu.linux_builder"]

  provisioner "shell" {
    execute_command = "echo '${var.ssh_password}' | sudo -S bash -c '{{ .Path }}'"
    script          = "scripts/provision.sh"
  }

  provisioner "shell" {
    execute_command = "echo '${var.ssh_password}' | sudo -S bash -c '{{ .Path }}'"
    script          = "scripts/cleanup.sh"
  }

  post-processor "shell-local" {
    inline = [
      "echo 'Converting raw image to qcow2...'",
      "qemu-img convert -f qcow2 -O qcow2 -c output-linux_builder/packer-linux_builder output-linux_builder/${var.output_filename}",
      "echo 'Removing intermediate image...'",
      "rm -f output-linux_builder/packer-linux_builder",
      "echo 'Build complete: output-linux_builder/${var.output_filename}'"
    ]
    inline_shebang = "/bin/bash -e"
  }
}
```

### `http/preseed.cfg` — Ubuntu/Debian only

```cfg
# Fully-automatic Debian/Ubuntu preseed
# Packer serves this via its built-in HTTP server; the boot command passes the URL.

d-i debian-installer/locale string en_US.UTF-8
d-i keyboard-configuration/xkb-keymap select us
d-i netcfg/choose_interface select auto
d-i netcfg/get_hostname string packer-build
d-i netcfg/get_domain string lsocaldomain

d-i mirror/country string manual
d-i mirror/http/hostname string <MIRROR_HOSTNAME>
d-i mirror/http/directory string /ubuntu
d-i mirror/http/proxy string

d-i passwd/root-login boolean false
d-i passwd/user-fullname string <SSH_USERNAME>
d-i passwd/username string <SSH_USERNAME>
d-i passwd/user-password password <SSH_PASSWORD>
d-i passwd/user-password-again password <SSH_PASSWORD>
d-i passwd/user-default-groups string sudo

d-i clock-setup/utc boolean true
d-i time/zone string UTC

d-i partman-auto/method string lvm
d-i partman-auto-lvm/guided_size string max
d-i partman-auto/choose_recipe select atomic
d-i partman-partitioning/confirm_write_new_label boolean true
d-i partman/choose_partition select finishs
d-i partman/confirm boolean true
d-i partman/confirm_nooverwrite boolean true

tasksel tasksel/first multiselect minimal
d-i pkgsel/include string openssh-server curl
d-i pkgsel/upgrade select full-upgrade

d-i grub-installer/only_debian boolean true
d-i grub-installer/with_other_os boolean true
d-i grub-installer/bootdev string default

d-i finish-install/reboot_in_progress note
```

For Ubuntu 20.04+ using `subiquity` (autoinstall), replace preseed.cfg with a `user-data` file in `http/`. See Constraints for the naming difference.

### `http/ks.cfg` — RHEL/Rocky/Alma only

```cfg
# Kickstart for RHEL-family (Rocky/Alma/RHEL 8+)
# Packer serves this via its built-in HTTP server.

text
lang en_US.UTF-8
keyboard us
timezone UTC --utc
network --bootproto=dhcp --hostname=packer-build

rootpw --lock
user --name=<SSH_USERNAME> --password=<SSH_PASSWORD> --groups=wheel --gecos="Packer Build User"

clearpart --all --initlabel
autopart --type=lvm

bootloader --location=mbr

%packages
@^minimal-environment
openssh-server
curl
# <USER_PACKAGES>
%end

%post
systemctl enable sshd
# Allow wheel group to sudo without password (Packer needs this for provisioners)
echo '%wheel ALL=(ALL) NOPASSWD: ALL' >> /etc/sudoers.d/packer
%end

reboot
```

### `scripts/cleanup.sh`

```bash
#!/usr/bin/env bash
set -euo pipefail

# ── Package cache ──────────────────────────────────────────────────────────────
if command -v apt-get &>/dev/null; then
  apt-get autoremove -y
  apt-get clean
  rm -rf /var/lib/apt/lists/*
elif command -v dnf &>/dev/null; then
  dnf clean all
  rm -rf /var/cache/dnf
fi

# ── SSH host keys — removed so they regenerate uniquely on first boot ──────────
rm -f /etc/ssh/ssh_host_*

# ── Machine identity ───────────────────────────────────────────────────────────
truncate -s 0 /etc/machine-id
rm -f /var/lib/dbus/machine-id
ln -sf /etc/machine-id /var/lib/dbus/machine-id

# ── Cloud-init state — reset so it reruns on first boot ───────────────────────
if command -v cloud-init &>/dev/null; then
  cloud-init clean --logs
fi

# ── Logs and temporary files ───────────────────────────────────────────────────
find /var/log -type f -exec truncate -s 0 {} \;
rm -rf /tmp/* /var/tmp/*
history -c 2>/dev/null || true
cat /dev/null > /root/.bash_history

# ── Zero free space — improves qcow2 compression ratio ────────────────────────
dd if=/dev/zero of=/EMPTY bs=1M 2>/dev/null || true
rm -f /EMPTY
sync
```

## Distro-Specific Boot Commands

Insert the correct value into `locals.boot_command` in `linux.pkr.hcl`. These are the only values that differ significantly between distros.

### Ubuntu 18.04 / Debian (legacy preseed)

```hcl
boot_command = [
  "<esc><wait>",
  "auto url=http://{{ .HTTPIP }}:{{ .HTTPPort }}/preseed.cfg ",
  "hostname=packer-build ",
  "domain=localdomain ",
  "interface=auto ",
  "DEBIAN_FRONTEND=newt<enter>"
]
```

### Ubuntu 20.04+ (subiquity / autoinstall)

The `http/` directory must contain `user-data` (not `preseed.cfg`) and an empty `meta-data` file.

```hcl
boot_command = [
  "<esc><wait>",
  "e<wait>",
  "<down><down><down><end>",
  " autoinstall ds=nocloud-net;s=http://{{ .HTTPIP }}:{{ .HTTPPort }}/",
  "<f10>"
]
```

### Rocky / Alma / RHEL 8+

```hcl
boot_command = [
  "<tab><wait>",
  " inst.ks=http://{{ .HTTPIP }}:{{ .HTTPPort }}/ks.cfg",
  " inst.cmdline<enter>"
]
```

## Steps Claude Must Follow

1. Confirm the distro family if not provided — this is always the first question.
2. Confirm the distro version and slug for the directory name.
3. Choose the correct `http/` file: `preseed.cfg` for legacy Debian/Ubuntu, `user-data` + `meta-data` for Ubuntu 20.04+ autoinstall, `ks.cfg` for RHEL family. Emit only one.
4. Insert the correct `boot_command` into `locals` in `linux.pkr.hcl`.
5. Embed the user's package list in `scripts/provision.sh`. If none provided, leave the clearly labelled placeholder section.
6. Emit all files (`linux.pkr.hcl`, `variables.pkrvars.hcl`, `http/<autoinstall_file>`, `scripts/provision.sh`, `scripts/cleanup.sh`) as a complete set.
7. Invoke the `readme-writer` skill to generate `README.md` in the same directory. The README must note: (a) `variables.pkrvars.hcl` must be populated before running `packer build`, (b) `ssh_password` must match the value in the preseed/ks file, (c) KVM acceleration requires the build host to have `/dev/kvm` accessible, (d) the output image lands in `output-linux_builder/<output_filename>`.
8. State which placeholder values remain and where to set them.

## Constraints

- Do not use `communicator = "none"` — Linux images use SSH provisioners for customisation. The Windows template's `communicator = "none"` pattern does not apply here.
- Do not include `curtin/`, `drivers/`, or any Windows-specific directories or files.
- Do not hardcode ISO URLs, checksums, usernames, or passwords — always use variables or placeholders.
- Do not add `format = "raw"` to the source block. The QEMU source writes qcow2 natively; no intermediate raw conversion is needed (unlike the Windows template).
- The post-processor uses `-c` (compression) on `qemu-img convert` by default. Remove it only if the user explicitly asks for an uncompressed image.
- `accelerator = "kvm"` is always set. If the user's build host does not support KVM, they must set it to `"none"` in `variables.pkrvars.hcl` — document this in the README but do not change the default.
- `ssh_password` in `variables.pkrvars.hcl` must match the value in `preseed.cfg` / `ks.cfg`. State this dependency explicitly in the README.
- `machine_type = "q35"` is always set; do not change it to `pc`.
- `disk_interface = "virtio"` and `net_device = "virtio-net"` are always used for Linux. Do not use `sata` or `e1000` (those are Windows-specific from the Windows template).
- Do not add a `floppy_files` block — Linux autoinstall mechanisms use the HTTP server, not a virtual floppy.
- `cleanup.sh` always zeroes free space and removes SSH host keys. These are not optional — they are required for a distributable golden image.
- Do not commit `variables.pkrvars.hcl` with real credentials. Note in the README that it should be listed in `.gitignore`.
- `output-linux_builder/` is a generated artefact — add it to `.gitignore` in the README usage notes.
