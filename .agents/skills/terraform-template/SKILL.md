# Terraform Template Skill

## Behaviour

- Ask only the single most-blocking unknown before proceeding. If the user has described the resources they want, proceed directly.
- Infer all resource names and variable defaults from existing templates. Never invent env-specific values (auth URLs, account IDs, project names, flavor/image names).
- Mark every env-specific unknown as a clearly labelled placeholder: `<OPENSTACK_AUTH_URL>`, `<TENANT_NAME>`, `<FLAVOR_NAME>`, etc.
- Produce all files as a complete set. Do not emit a single file in isolation unless the user explicitly asks for it.
- After emitting all `.tf` files, invoke the `readme-writer` skill to generate `README.md` in the same directory.

---

## File Set

Every template produces exactly these files:

```
<nn>-<slug>/
├── provider.tf
├── vars.tf
├── main.tf
├── datasource.tf
├── locals.tf
├── outputs.tf
├── cloud-init.yaml
├── testdeploy.tfvars
├── templates/
│   └── host_inventory.tftpl
└── README.md                  ← generated by readme-writer skill
```

`inventory.yml` is written to the module directory at `terraform apply` time by the `local_file` resource in `outputs.tf` — it is not a static file in the template set.

No `backend.tf` is generated by default. If the user explicitly asks for remote state, add one and ask for the bucket/workspace details first.

## Canonical File Templates

### `provider.tf`

```hcl
terraform {
  required_version = ">= 0.14.0"
  required_providers {
    openstack = {
      source  = "terraform-provider-openstack/openstack"
      version = "~> 3.0.0"
    }
    local = {
      source  = "hashicorp/local"
      version = "~> 2.4"
    }
  }
}

# Public endpoint — used for all standard resource operations
provider "openstack" {
  insecure      = true
  endpoint_type = "public"
  user_name     = var.openstack_user_name
  tenant_name   = var.openstack_tenant_name
  password      = var.openstack_password
  auth_url      = var.openstack_auth_url
  region        = var.openstack_region
  domain_name   = "Default"
}

# Admin endpoint — used only for privileged operations (e.g. Glance image upload)
provider "openstack" {
  alias         = "admin_interface"
  insecure      = true
  endpoint_type = "admin"
  user_name     = var.openstack_user_name
  tenant_name   = var.openstack_tenant_name
  password      = var.openstack_password
  auth_url      = var.openstack_auth_url
  region        = var.openstack_region
  domain_name   = "Default"
}
```

### `vars.tf`

```hcl
# --- Provider credentials (required, no defaults) ---
variable "openstack_user_name"   {}
variable "openstack_tenant_name" {}
variable "openstack_password"    {}
variable "openstack_auth_url"    {}
variable "openstack_region"      {}

# --- Resource identity ---
variable "custom_name" {
  description = "Naming prefix applied to all created resources."
  default     = "demo-run"
}

variable "flavor_name" {
  default = "m1.tiny"
}

variable "image_name" {
  description = "Name of the Glance image to look up when deploy_image = false."
  default     = "<IMAGE_NAME>"
}

variable "glance_image_name" {
  description = "Local filename of the image to upload when deploy_image = true."
  default     = "<IMAGE_FILENAME>"
}

variable "security_group" {
  default = "default"
}

variable "ssh_key_pair" {
  default = "mykey"
}

variable "cidr" {
  description = "Base CIDR for subnet allocation. Third octet is auto-incremented per index when resourcecount[\"net\"] > 1."
  type        = string
  default     = "172.16.0.0/24"
}

# --- Resource counts ---
# Set any key to 1 for a single resource, or N for bulk. net must equal inst.
variable "resourcecount" {
  type = map(number)
  default = {
    net  = 1
    vol  = 1
    inst = 1
    imgs = 1
  }
}

# --- Conditional deployment flags ---
variable "deploy_image" {
  type    = bool
  default = false
}

variable "deploy_volume" {
  type    = bool
  default = false
}
```

### `main.tf`

```hcl
resource "openstack_networking_network_v2" "network" {
  count = var.resourcecount["net"]
  name  = "${var.custom_name}-net-${count.index}"
}

resource "openstack_networking_subnet_v2" "subnet" {
  count      = var.resourcecount["net"]
  name       = "${var.custom_name}-subnet-${count.index}"
  network_id = openstack_networking_network_v2.network[count.index].id
  cidr       = "172.16.${count.index}.0/24"
  ip_version = 4
}

resource "openstack_images_image_v2" "image" {
  count            = var.deploy_image ? var.resourcecount["imgs"] : 0
  provider         = openstack.admin_interface
  name             = "${var.custom_name}-image-${count.index}"
  local_file_path  = "${path.module}/${var.glance_image_name}"
  container_format = "bare"
  disk_format      = "qcow2"
}

resource "openstack_blockstorage_volume_v3" "volume" {
  count       = var.deploy_volume ? var.resourcecount["vol"] : 0
  name        = "${var.custom_name}-vol-${count.index}"
  size        = 2
  volume_type = "<VOLUME_TYPE>"
}

resource "openstack_compute_instance_v2" "vm" {
  count       = var.resourcecount["inst"]
  name        = "${var.custom_name}-instance-${count.index}"
  image_id    = local.selected_image_id
  flavor_name = var.flavor_name
  user_data   = file("${path.module}/cloud-init.yaml")

  network {
    name = "${var.custom_name}-net-${count.index}"
  }

  depends_on = [
    openstack_networking_network_v2.network,
    openstack_networking_subnet_v2.subnet,
  ]
}

resource "openstack_compute_volume_attach_v2" "attach" {
  count       = var.deploy_volume ? var.resourcecount["vol"] : 0
  instance_id = openstack_compute_instance_v2.vm[count.index].id
  volume_id   = openstack_blockstorage_volume_v3.volume[count.index].id
}
```

### `datasource.tf`

```hcl
data "openstack_compute_flavor_v2" "flavor_name" {
  name = var.flavor_name
}

# Looked up only when not uploading a new image; count = 0 suppresses it when deploy_image = true
data "openstack_images_image_v2" "existing_image" {
  count = var.deploy_image ? 0 : 1
  name  = var.image_name
}
```

### `locals.tf`

```hcl
locals {
  # Select the uploaded image when deploy_image = true, otherwise use the looked-up existing image
  selected_image_id = var.deploy_image \
    ? openstack_images_image_v2.image[0].id \
    : data.openstack_images_image_v2.existing_image[0].id

  # ISO 8601 timestamp embedded in the generated Ansible inventory header
  timestamp = formatdate("YYYY-MM-DD hh:mm:ss ZZZ", timestamp())
}
```

### `outputs.tf`

```hcl
# Map of VM name → primary IP — primary reference for post-deploy and Ansible work
output "vm_ip_map" {
  description = "Map of deployed VM name to its assigned IP address."
  value = {
    for vm in openstack_compute_instance_v2.vm :
    vm.name => vm.access_ip_v4
  }
}

output "network_names" {
  value       = openstack_networking_network_v2.network[*].name
  description = "Names of all created networks."
}

output "subnet_names" {
  value       = openstack_networking_subnet_v2.subnet[*].name
  description = "Names of all created subnets."
}

output "image_name" {
  value       = var.deploy_image ? openstack_images_image_v2.image[0].name : data.openstack_images_image_v2.existing_image[0].name
  description = "Name of the Glance image used for instance creation."
}

output "volume_names" {
  value       = var.deploy_volume ? openstack_blockstorage_volume_v3.volume[*].name : ["No volume deployed"]
  description = "Names of all Cinder volumes created."
}

# Ansible inventory written to the module directory on every apply
resource "local_file" "ansible_inventory" {
  filename = "${path.module}/inventory.yml"
  content = templatefile("${path.module}/templates/host_inventory.tftpl", {
    vms = {
      for vm in openstack_compute_instance_v2.vm :
      vm.name => { primary_ip = vm.access_ip_v4 }
    }
    timestamp = local.timestamp
  })
  depends_on = [openstack_compute_instance_v2.vm]
}

output "ansible_inventory_path" {
  value       = local_file.ansible_inventory.filename
  description = "Path to the generated Ansible inventory file."
}

output "terraform_outputs_summary" {
  description = "Consolidated deployment summary."
  value = {
    total_vms_deployed = length(openstack_compute_instance_v2.vm)
    vm_names           = openstack_compute_instance_v2.vm[*].name
    vm_ip_map          = { for vm in openstack_compute_instance_v2.vm : vm.name => vm.access_ip_v4 }
    ansible_inventory  = local_file.ansible_inventory.filename
    deployment_complete = "true"
  }
}
```

### `templates/host_inventory.tftpl`

```yaml
---
# Ansible Inventory — Auto-generated by Terraform
# Generated: ${timestamp}
# All hosts use SSH key authentication. Do not edit manually; re-run tofu apply to regenerate.

all:
  children:
    deployed_vms:
      description: "VMs deployed via Terraform on OpenStack"
      hosts:
%{ for vm_name, vm_data in vms ~}
        ${vm_name}:
          ansible_host: ${vm_data.primary_ip}
          ansible_user: ubuntu
          ansible_ssh_private_key_file: "~/.ssh/id_rsa"
          ansible_python_interpreter: /usr/bin/python3
%{ endfor ~}

      vars:
        ansible_become_method: sudo
        ansible_become_user: root
```

Rules:
- The `%{ for ... ~}` / `%{ endfor ~}` strip-whitespace markers (`~`) are mandatory — omitting them produces extra blank lines in the rendered YAML.
- The `ansible_ssh_private_key_file` path is a placeholder — note it in the README as a value the operator must verify.
- Add group `vars` entries only when the user specifies them. Do not pad with NTP/DNS defaults unless asked.

## Naming Conventions

| Element | Pattern | Example |
|---------|---------|---------|
| Resource names | `${var.custom_name}-{type}-${count.index}` | `demo-run-net-0` |
| Terraform resource labels | snake_case, singular | `network`, `subnet`, `vm`, `volume` |
| Variable names — provider | `openstack_*` | `openstack_auth_url` |
| Variable names — resources | descriptive snake_case | `flavor_name`, `custom_name` |
| Data source labels | describe lookup type | `existing_image`, `flavor_name` |
| Output names | `{resource_type}_{attribute}` (plural for lists, `_map` suffix for maps) | `vm_ip_map`, `network_names` |
| Directory | `{nn}-{slug}/` where nn is zero-padded two digits | `03-deploy-lb/` |

---

## Conditional Deployment Patterns

| Scenario | Pattern |
|----------|---------|
| Optional resource (any count) | `count = var.deploy_X ? var.resourcecount["X"] : 0` |
| Data source absent when uploading | `count = var.deploy_image ? 0 : 1` |
| Image selection via locals | `var.deploy_image ? resource[0].id : data_source[0].id` |
| Output for count-based resource | `resource[*].attribute` (splat, returns list) |
| Output name→IP map | `{ for vm in resource[*] : vm.name => vm.access_ip_v4 }` |
| Output fallback for undeployed | `var.deploy_X ? resource[*].name : ["No X deployed"]` |

## Steps Codex Must Follow

1. Confirm the directory slug and `custom_name` prefix with the user, or use placeholders.
2. Identify which optional resources are needed (image upload, volume, volume attachment). Ask if not stated.
3. Emit all files (`provider.tf`, `vars.tf`, `main.tf`, `datasource.tf`, `locals.tf`, `outputs.tf`, `cloud-init.yaml`, `testdeploy.tfvars`, `templates/host_inventory.tftpl`) as a complete set.
4. Replace `<VOLUME_TYPE>` with the value the user provides, or leave as placeholder.
5. Invoke the `readme-writer` skill to generate `README.md` in the same directory, treating the generated `.tf` files as the source material. The README must note: (a) `net` count must equal `inst` count, (b) `inventory.yml` is written on `tofu apply`, (c) `ansible_ssh_private_key_file` path must be verified before running Ansible.
6. State which placeholder values remain and where to set them.

---

## Constraints

- Do not emit `backend.tf` unless explicitly requested.
- Do not hardcode auth URLs, passwords, tenant names, or flavor/image names — always use variables or placeholders.
- Do not add `lifecycle` or `timeouts` blocks unless the user asks. The exception is the existing Proxmox module which already uses `lifecycle.ignore_changes` — do not remove it if present.
- Do not create a `modules/` subdirectory — OpenStack templates in this repo are flat by convention.
- Do not add `tags` — OpenStack Neutron/Nova do not use AWS-style tag maps.
- `domain_name = "Default"` is always hardcoded; never expose it as a variable.
- `insecure = true` is always set; never remove it or make it conditional.
- Never add a `validation` block unless the user asks.
- `inventory.yml` is a generated artefact — add it to `.gitignore` in the README usage notes.
- The `local_file` resource belongs in `outputs.tf` — do not move it to `main.tf`.
- All `output` blocks must include a `description`.
